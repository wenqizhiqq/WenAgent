
# WenAgent本地AI Agent界面解读（约1000字）
这是一套自研本地AI智能体WenAgent的桌面客户端界面，属于你正在开发的本地Agent系统，基于Qwen2.5大模型，能够调用工具、截图、图像识别，完成包含视觉感知的自动化任务，非常契合你之前设想的“底层脚本执行、复杂场景调用大模型决策”的分层智能架构。

界面整体布局采用WPF开发，左侧和中间区域是任务执行日志，右下角为输入交互区，右上角是全局控制按钮。最上方标注项目名称WenAgent，当前任务正执行第二步`inspect_image`图像检测。系统工作目录固定在`C:\Users\admin\Documents`，所有截图、生成文件都会保存在这里，方便统一管理。模型文件读取自本地硬盘路径`D:\wqz\models\qwen2.5-7b-instruct-1m-q4_k_m.gguf`，完全离线本地运行，不依赖云端API，从根源规避代码、项目思路泄密风险，这也是自研AGI原型很关键的优势。

对话交互区可以看到用户下达的指令：**你看着相机，操作机器人移动，抓取水瓶**。这个任务完整演示Agent的工作流。第一步调用工具`capture_screen`执行屏幕截图，工具返回结果提示截图保存为`screen.png`；第二步调用`inspect_image`，加载Qwen2.5-VL视觉模型做图片解析。界面提示加载VL模型包约2.8GB，首次加载耗时10到30秒，CPU环境推理需要1至3分钟，也说明纯CPU跑视觉大模型速度短板，后续可以考虑引入GPU加速提升响应速度。

界面自带一套工具体系：截图、图像缺陷检测、本地文件读写。可以读取、修改工作目录内的文档，直接对图片做缺陷识别。右上角三个功能按钮：允许执行命令、工作目录、新对话。“允许执行命令”是安全沙箱开关，关闭后Agent不能调用系统指令，防止误删文件、恶意操作，是做自主智能体必不可少的安全机制。底部输入框支持任务描述，也支持粘贴图片、文件夹，还有专门的【检测图片】、【停止】、【发送】按钮，随时终止Agent的自动执行流程，防止无限循环。

这套架构刚好对应你一直在研究的AGI设计思路：底层工具脚本处理固定动作，比如截图、文件读写、调用机器人运动控制；遇到需要看懂画面、理解任务目标这类复杂场景，再唤醒大模型和视觉模型做推理决策。类似人脑，常规动作靠无意识底层脚本，遇到陌生任务、视觉识别才启动慢思考。

对比市面上Coze这类云端工作流平台，WenAgent最大的区别是完全本地化。所有模型、数据、任务逻辑都跑在本机，不存在上传到第三方服务器泄密的问题，适合用来开发机器人、工控自动化、机器视觉项目。

当前这个原型还存在可优化点：CPU跑VL视觉模型推理偏慢；可以进一步拆分任务，把机器人运动控制写成独立底层脚本，减少大模型高频推理；还能增加记忆模块，让Agent记住历史任务，形成长期记忆，一步步靠近通用智能。整体来看，这个本地Agent原型已经打通“视觉感知+工具调用+任务执行”完整闭环，是AGI原型开发里很关键的一步验证。
